What Is Morse Code?

Morse code is a method of transmitting text information as a series of on-off tones, lights, or clicks. It represents letters, numbers, and punctuation with a standardized sequence of short and long signals. Short signals are called "dots" (·) and long signals are called "dashes" (–).

## Historical Context
Morse code was developed in the 1830s and 1840s by Samuel Morse and Alfred Vail. It was created to be used with the electric telegraph, which was one of the first practical systems for long-distance communication. Morse code became essential for 19th and 20th-century communication, especially in railways, shipping, and military operations. The most famous sequence is SOS: ··· ––– ···, which was adopted as the international distress signal.

## How Morse Code Works
Morse code assigns a unique pattern of dots and dashes to each letter of the alphabet and to numbers. 
- **Dot (·)**: a short signal
- **Dash (–)**: a signal about 3 times longer than a dot
- **Space between signals**: separates letters within a word
- **Space between words**: separates words

For example:
- A = ·–
- B = –···
- C = –·–·
- SOS = ··· ––– ···

The timing and spacing are critical for the message to be decoded correctly.
